# Run and debug

- **Ctrl+F5** builds, then runs the active application. The previous Run is closed first, so tabs no longer pile up in the terminal panel.
- **F5** builds, then starts the debugger of the Qt kit (GDB, LLDB or the Visual Studio debugger). Qt for Python projects use the Python debugger.
- The **Run Debug** button of the Workspace view starts the debugger without rebuilding.
- **Run options** sets arguments, working directory and where program output goes; the Qt runtime can be deployed automatically after each build.

These shortcuts are active only in QPM workspaces and can be changed in *Keyboard Shortcuts*.
