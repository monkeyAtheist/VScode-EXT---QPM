# Explore the bench tools

QPM includes tools for test-bench and embedded work, independent of any project:

- **Instrument diagnostics** — COM / USB / VISA terminal, SCPI presets, saved commands and PASS/FAIL sequences.
- **Network & wireless** — TCP/UDP client and listener, ping / DNS / port checks, Wi-Fi and BLE scans, BLE GATT inspection.
- **QPM devices** — one profile per instrument or board, grouping its COM, VISA, TCP, UDP and SSH endpoints.
- **SSH devices** — OpenSSH aliases and keys; one click turns an alias into the target of a Remote Linux platform.
