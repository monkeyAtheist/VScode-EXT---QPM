# Open or create a Qt project

A native QPM project is a **`.qtproject.json`** manifest: sources, forms, resources, QML, Qt modules, kits and profiles. Several projects can be grouped in a **`.cws`** workspace.

- **Open** an existing `.qtproject.json`, `.cws` or `.prj` (compatibility C/C++ project). QPM also opens it automatically when the folder you open in VS Code contains one.
- **Create** a Qt Widgets, Qt Quick, console, test or library starter — or a **Qt for Python (PySide6)** application.

Recently opened projects and workspaces are listed on the Home page.
