# Build with Ctrl+F7

The status bar shows the active configuration, for example `Scope · D64 · EXE`. Click it to switch between **D32 / R32 / D64 / R64**, **EXE / DLL / LIB**, the Qt installation and the target platform.

- **Ctrl+F7** builds the active project with the QPM direct build, qmake or CMake backend (moc, uic and rcc run automatically).
- Errors and warnings go to the **Problems** view; their count appears in the status bar and on Home.
- **Project Settings** holds every option: Qt modules, kit, backend, flags, deployment, platforms, tests and packaging.
