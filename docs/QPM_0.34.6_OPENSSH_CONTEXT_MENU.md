# QPM 0.34.6 — OpenSSH context menu integration

The OpenSSH Device Manager is available from:

- editor right click -> QPM -> OpenSSH Device Manager;
- VS Code Explorer right click -> QPM -> OpenSSH Device Manager;
- QPM workspace tree right click on a workspace, project or logical folder;
- Platforms view;
- Command Palette.

Command ID: `qpm.openSshDeviceManager`.
